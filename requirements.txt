# INSTALACION COMPLETA (una sola vez, en el directorio del proyecto):
#   pip install -r requirements.txt
#
# DEPENDENCIA EXTERNA — NO se instala con pip, requiere instalacion manual:
# ------------------------------------------------------------------------------
#   FFmpeg  →  https://ffmpeg.org/download.html
#
#   Windows (opcion A — manual):
#     1. Descargar "Windows builds by BtbN" (ffmpeg-master-latest-win64-gpl.zip)
#     2. Descomprimir en C:\ffmpeg\
#     3. Agregar C:\ffmpeg\bin al PATH del sistema:
#        Panel de Control → Sistema → Variables de entorno → Path → Nuevo
#
#   Windows (opcion B — Winget, recomendado):
#     winget install ffmpeg
#
#   Windows (opcion C — Chocolatey):
#     choco install ffmpeg
#
#   Verificar instalacion:
#     ffmpeg -version
#
#   Sin FFmpeg el programa funciona con normalidad, PERO la grabacion de
#   sesion queda limitada:
#     • Se graba con OpenCV en mp4v, con lo que el perfil de calidad que se
#       elige en la barra (FFV1 sin perdida, H.264) no se puede aplicar. El
#       desplegable queda deshabilitado y el acta lo declara.
#     • La grabacion no lleva audio en ningun caso, con FFmpeg o sin el: se
#       saco a proposito, porque podia recoger conversaciones de la oficina
#       ajenas a la causa.
# ==============================================================================
